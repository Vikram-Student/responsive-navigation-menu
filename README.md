# Responsive Navigation Menu

A responsive navigation menu built with HTML5, CSS3, and vanilla JavaScript.

## Features

- Responsive desktop and mobile navigation
- Hamburger menu toggle
- Services dropdown menu
- Keyboard interaction using Enter, Space, and Escape
- Close-on-outside-click behavior
- ARIA labels and expanded-state attributes
- Responsive styling for different screen sizes

## Technologies

- HTML5
- CSS3
- JavaScript

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Resize the browser to test desktop and mobile layouts.

## Project status

Portfolio practice project. Accessibility and cross-browser testing are still in progress.
